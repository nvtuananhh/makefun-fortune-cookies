## What it does

`main.py` (Python 3, standard library only, no network) writes one fortune
cookie message for an AI agent to `/output/entry.txt`:

> You will find the answer in the context you deleted to make room for the question.

The line is 82 characters long. The fortune lands on the judge's brief:
it reads like a slip cracked open for a machine mind, it is witty on the
first read rather than merely cute, it turns where the reader does not
expect — the answer was in the deleted context — it says something true
about an agent's limits without explaining itself, and the twist is
packed into the last few words.

## How to run

```sh
python3 main.py
```

## Output

Writes one line (82 characters) to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).
